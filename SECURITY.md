# Security Policy

## Supported versions

The latest released version on Hex.pm is supported for security fixes.

## Reporting a vulnerability

Do not open public issues for security vulnerabilities.

Instead, report privately through GitHub Security Advisories for this
repository:

- Go to the repository's `Security` tab.
- Click `Report a vulnerability`.
- Include reproduction details, impact, and affected versions.

We will acknowledge reports and work on a fix as quickly as possible.
